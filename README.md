# Virtueller PC-Bau

Interaktives Lernobjekt für den Informatikunterricht, Jahrgang 8 (WP Informatik, Sekundarschule).
Läuft im Browser, ohne Installation, ohne Server: eine einzelne HTML-Datei mit Inline-SVG.

## Was es macht

1. **Ausbau** — Ein PC wird Teil für Teil zerlegt. Klick auf ein Bauteil; geht es noch nicht,
   sagt das Programm warum („Erst den Netzstecker", „Auf der CPU sitzt der Kühler").
   Zu jedem Teil ein Erklärtext: Aufgabe im Rechner und der konkrete Handgriff beim Ausbau.
2. **Zusammenbau** — Derselbe Rechner rückwärts, ohne Hilfestellung. Fehlversuche werden gezählt.
3. **Fünf Fragen** — Kontrolle zum Von-Neumann-Prinzip, zu Speicher und zu EVA.

## Lehrplanbezug

Kernlehrplan WP Informatik GE/SK NRW (MSB 2023), Kapitel 2.2, Inhaltsfeld Informatiksysteme:
*erläutern grundlegende Prinzipien eines Von-Neumann-Rechners.* Dazu aus dem Inhaltsfeld
Information und Daten: *vergleichen Datenmengen hinsichtlich ihrer Größe mithilfe anschaulicher
Beispiele aus ihrer Lebenswelt.*

Das Lernobjekt ersetzt das Zerlegen eines echten Rechners nicht — es bereitet es vor:
Reihenfolge und Sicherheitsregeln sitzen, bevor mehrere Gruppen gleichzeitig schrauben.
